# Обычные виджеты

`DiaryWidget` входит в существующий `MalyshWidgets` вместе с Live Activities. Минимальная версия — iOS 26. Small показывает последнее завершённое кормление, его тип, время и интервал. Medium добавляет переходы «Грудь», «Подгузник», «Сон». Large показывает завершённые кормления, мокрые/смешанные подгузники, завершённый сон за локальные сутки и три последних события. Сон обрезается границами дня, пересечения объединяются. Незавершённые события остаются в Live Activities и в обычные итоги не входят.

Rectangular показывает последнее кормление и интервал; Circular — мокрые/смешанные подгузники сегодня; Inline — краткое кормление. Недоступный снимок показывает предложение открыть приложение и `—` вместо неподтверждённого числа. Известный пустой дневник показывает нулевые итоги.

## Данные и обновление

Core Data остаётся источником истины. Пути SQLite, модели, private/shared stores, CloudKit Sharing и исполнение Live Activity intents не меняются. Расширение не открывает базу и не обращается к сети.

Приложение атомарно записывает `diary-widget-v1.json` в App Group `group.dev.dimensi.malysh`. `WidgetSnapshot` содержит UUID/имя выбранного ребёнка, время формирования и проекцию завершённых событий без заметок и данных родителей. Сохраняются восемь дней (до 4096 записей), дополнительно последнее кормление и три последних события тихого дневника. Файл исключён из backup, защищён до первого разблокирования после перезагрузки. Неизвестная версия или oversized-кэш не используется. Ошибка записи кэша не отменяет успешное сохранение дневника; удаление кэша не удаляет Core Data.

Успешный `AppStore.reload()` публикует снимок и запрашивает `WidgetCenter.reloadTimelines(ofKind:)` только для обычного виджета. Этот путь покрывает добавление, исправление, удаление, выбор ребёнка, shared diary, remote-change, успешные CloudKit events и foreground. Уведомления суток, времени и часового пояса обновляют снимок при работающем процессе.

`TimelineProvider` читает кэш и заранее выдаёт семь записей на следующие локальные полуночи. Запрос следующей загрузки — через 30 минут. Системный относительный `Text` обновляет интервал без фонового Timer. WidgetKit и CloudKit зависят от iOS: reload не гарантирует немедленного выполнения, завершённый процесс не получает каждое уведомление времени. Смена часового пояса применяется при следующем выполнении provider или приложения. Large показывает время формирования снимка.

## Переходы

Схема `malysh://widget/<сценарий>?baby=<UUID>` зарегистрирована в Info.plist. Сценарии: `today`, `breast`, `diaper`, `sleep`, `history`. Открытие URL не создаёт запись: грудь и подгузник открывают существующий привязанный диалог; сон требует явного подтверждения запуска. Уже идущий сон открывает «Сегодня».

Холодный запуск ждёт загрузки дневника; открытая форма сначала закрывается, прокрученный экран возвращается к исходной карточке. Ссылка на другого/недоступного ребёнка игнорируется, чтобы не записать событие в неправильный дневник. Обновлённый снимок использует текущего выбранного ребёнка.

## Дизайн и приватность

SF Symbols, системные шрифты и существующие `Feeding`, `Diaper`, `Sleep` сохраняют визуальный язык приложения. Пастельные подложки содержат контрастные иконки. `containerBackground(for: .widget)` оставляет системе управление фоном, tinted/clear и Liquid Glass; accented/vibrant работают без различения цветов. Выбранный Dynamic Type сохраняется без ограничения размера шрифта. На accessibility-размерах Small отдаёт приоритет интервалу последнего кормления, Rectangular на самых крупных размерах — времени события с иконкой его типа, Medium сохраняет три перехода с семантическими иконками, Large располагает дневные итоги вертикальными строками. Circular оставляет число; Inline показывает краткий интервал, а если даже одна строка выбранного шрифта не помещается — семантическую иконку с полной VoiceOver-подписью; для недоступных данных показывается `—`, а в тесном Inline — иконка открытия приложения. Второстепенные сведения сокращаются по доступной площади, VoiceOver получает полные подписи кормления и последних событий.

Весь персональный контент отмечен `.privacySensitive()` и следует настройкам конфиденциальных данных WidgetKit на заблокированном устройстве. Пользовательские настройки экрана блокировки не меняются.

## Подпись

Обе цели требуют `com.apple.security.application-groups = [group.dev.dimensi.malysh]`. Основное приложение сохраняет iCloud/APNs entitlements, расширение получает только App Group. Зарегистрируйте группу в Team `YBBAN7R28K`, назначьте обоим explicit App ID и пересоздайте оба development/distribution profiles. Исходные entitlements не доказывают подпись готового продукта. `Scripts/ci-signing.sh` отклоняет distribution profiles без группы. См. [TestFlight.md](TestFlight.md); эта функция не запускает выпуск.

## Проверки

`WidgetSnapshotTests` проверяет допустимость/приватность проекции, восстановление снимка из SQLite и выбор ребёнка. `WidgetRouteTests` — URL и identity. `WidgetSystemUITests` устанавливает настоящий Medium в SpringBoard и проверяет данные и три перехода в работающий процесс. Два сценария системных кнопок Live Activities входят в общий прогон.

Состав и условия запуска задаёт [матрица тестов](TestMatrix.md). Расчёты календаря/DST проверяет `DomainTests`. Внешний вид семейств, темы, крупный текст, tinted/clear, privacy и холодные переходы проверяются вручную при изменении этой области. Отдельного target для PNG и сравнения пикселей нет. Физический защищённый Lock Screen и доставка между Apple ID требуют устройств; локальные проверки их не доказывают.

Для simulator-проверок используйте ad hoc подпись (`CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=-`), как в `Scripts/check.sh`: без подписи simulator не назначает App Group containers. Эта подпись не является Apple Developer device/distribution-проверкой.
