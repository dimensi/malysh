# TestFlight по тегу версии

Workflow `.github/workflows/testflight.yml` предназначен для репозитория `dimensi/malysh`. Он запускается только при отправке тега вида `vX.Y.Z`, например `v1.2.3`. Обычный push ветки не загружает приложение. Коммит тега должен входить в историю `origin/main`; неправильный тег или коммит вне `main` останавливает работу до установки материалов подписи.

## Настройка GitHub Secrets

Добавьте секреты в Settings → Secrets and variables → Actions:

| Секрет | Содержимое |
| --- | --- |
| `IOS_DISTRIBUTION_P12_BASE64` | Base64 сертификата Apple Distribution вместе с закрытым ключом в `.p12` |
| `IOS_DISTRIBUTION_P12_PASSWORD` | Пароль экспорта `.p12` |
| `IOS_PROVISIONING_PROFILE_BASE64` | Base64 профиля распространения App Store Connect для `dev.dimensi.malysh` |
| `IOS_WIDGET_PROVISIONING_PROFILE_BASE64` | Base64 отдельного профиля App Store Connect для `dev.dimensi.malysh.widgets` (обязателен) |
| `ASC_PRIVATE_KEY_BASE64` | Base64 закрытого ключа App Store Connect API (`.p8`) |
| `ASC_KEY_ID` | Идентификатор API-ключа |
| `ASC_ISSUER_ID` | Issuer ID команды App Store Connect |

Сертификат, профиль и API-ключ должны относиться к команде `YBBAN7R28K`. Профиль должен разрешать нужные возможности приложения, включая CloudKit в Production. У API-ключа должны быть права на чтение сборок и загрузку приложения. Закрытые ключи и пароли нельзя добавлять в репозиторий, issue, отчёты или журналы.

Для CI создан отдельный ручной профиль `Malysh GitHub Actions App Store` с уже существующим сертификатом Apple Distribution. Профиль, автоматически управляемый Xcode, для ручной подписи CI не используется. Текущий сертификат и соответствующий профиль действуют до **4 декабря 2026**: до этой даты обновите сертификат/профиль и соответствующие секреты GitHub, чтобы следующие выпуски продолжали подписываться.

Скрипт `Scripts/ci-signing.sh setup` устанавливает материалы во временные файлы и отдельную связку ключей. Он передаёт следующим шагам через `GITHUB_ENV` значения `PROFILE_UUID`, `PROFILE_NAME`, `WIDGET_PROFILE_UUID`, `CI_KEYCHAIN_PATH`, `CI_KEYCHAIN_PASSWORD` и `ASC_KEY_PATH`; пароль связки должен быть замаскирован в журнале. Подкоманда `cleanup` выполняется даже после ошибки и должна безопасно работать, если установка не началась или завершилась частично. Профили и сертификаты имеют срок действия: обновляйте секреты до истечения или после отзыва. При отзыве API-ключа замените также его ID и закрытый ключ.

## Однократная настройка расширения Live Activity

Перед следующим выпуском зарегистрируйте в Apple Developer отдельный explicit App ID `dev.dimensi.malysh.widgets` в команде `YBBAN7R28K`. Для расширения не нужны CloudKit или Push Notifications. Для обычных виджетов обеим целям требуется App Group `group.dev.dimensi.malysh`: зарегистрируйте её в Team, назначьте App ID `dev.dimensi.malysh` и `dev.dimensi.malysh.widgets`, затем пересоздайте оба профиля. Обновите `IOS_PROVISIONING_PROFILE_BASE64` и `IOS_WIDGET_PROVISIONING_PROFILE_BASE64`; прежние профили без группы будут отклонены проверкой подписи. Создайте для этого ID отдельный ручной профиль App Store Connect с тем же сертификатом Apple Distribution и сохраните его Base64 в обязательном GitHub Secret `IOS_WIDGET_PROVISIONING_PROFILE_BASE64`. Профиль основного приложения остаётся отдельным. Эти действия выполняются владельцем аккаунта; изменения кода не создают App ID, профиль или секрет автоматически.

Скрипт проверяет оба профиля, устанавливает их без перезаписи существующих файлов и при очистке удаляет только принадлежащие этому запуску файлы. Fastlane передаёт `MALYSH_PROFILE_UUID` и `MALYSH_WIDGET_PROFILE_UUID`; каждая цель использует свой `PROVISIONING_PROFILE_SPECIFIER`. Экспорт IPA содержит соответствие обоих bundle ID своим профилям.

## Выпуск

После слияния нужных изменений в `main` создайте и отправьте тег:

```sh
git switch main
git pull --ff-only
git tag v1.2.3
git push origin v1.2.3
```

Workflow использует Intel-runner `macos-15-intel`, Xcode 26.3 и Ruby 4.0. Версия Xcode сверена с [образом GitHub runner](https://github.com/actions/runner-images/blob/main/images/macos/macos-15-Readme.md). Fastlane закреплён на `2.237.0` в `Gemfile`. Сначала запускаются unit- и UI-тесты: helper выбирает доступный iPhone Simulator с самой ранней установленной версией iOS не ниже 26.0. Затем устанавливаются материалы подписи и собирается уже сохранённый в репозитории `Malysh.xcworkspace`; Tuist в CI не запускается.

Версия приложения берётся из тега без `v`. Номер сборки — последний номер TestFlight для этой версии плюс один; при отсутствии сборок используется `1`. Это учитывает ранее загруженные вручную сборки. Существующий номер должен быть целым числом. Запуски TestFlight выполняются последовательно, без отмены предыдущего. Не загружайте вручную другую сборку той же версии одновременно с CI; перед повторным запуском после успешной загрузки дождитесь появления предыдущей сборки в App Store Connect.

Подпись ручная, среда CloudKit — Production. Загрузка не отправляет сборку на внешнее тестирование и не меняет состав тестировщиков. Для существующей внутренней группы `parents` включён `hasAccessToAllBuilds`: после обработки Apple новые сборки доступны участникам автоматически. Workflow не ждёт завершения обработки Apple: зелёный шаг загрузки ещё не означает, что сборка уже доступна в TestFlight. Проверьте обработку, доступность в группе и предупреждения в App Store Connect.

## Результаты и ограничения

GitHub хранит только результаты тестов и журналы сборки в течение семи дней. IPA, архив Xcode и материалы подписи не публикуются как артефакты. Workflow не создаёт исходный ZIP-архив; автоматически предоставляемые GitHub ссылки на исходники тега не являются действием этого workflow.

Ранее подтверждённый полный выпуск — [v1.0.7](https://github.com/dimensi/malysh/actions/runs/41883874325), исходный коммит `c491f3a`, длительность 24 минуты 39 секунд. Прошли 35 тестов (29 unit + 6 UI), установка подписи, сборка, загрузка, очистка временных материалов и сохранение результатов. App Store Connect API подтвердил **1.0.7 (1)**, MinimumOSVersion=26.0, `VALID` / `IN_BETA_TESTING`, `usesNonExemptEncryption=false` и назначение группе `parents`. Номер нового выпуска был выбран автоматически.

[CI v1.0.8](https://github.com/dimensi/malysh/actions/runs/41891802688), исходный коммит `ae74e78`, прошёл 43 unit и 7 UI, но один UI-тест не смог закрыть native popover нажатием снаружи на iOS 26. Подпись, экспорт и загрузка были пропущены; бинарник 1.0.8 не загружен. Cleanup и сохранение артефактов прошли. Подтверждение удаления затем заменено на native alert с видимыми кнопками «Отмена» и удаления; тест обращается к точным кнопкам alert без координат. Целевой локальный сценарий прошёл 1/1, после чего исправление вошло в 1.0.9.

[CI v1.0.9](https://github.com/dimensi/malysh/actions/runs/41896860503), исходный коммит `8b0c1e2b78174e80e6b64da167f269e004d50a5a`, успешно завершился за **25 минут 26 секунд**. Полный набор **51/51** (43 unit + 8 UI), подпись, экспорт, загрузка, cleanup и сохранение артефактов прошли. App Store Connect независимо подтвердил **1.0.9 (1)**, MinimumOSVersion=26.0, `VALID` / `IN_BETA_TESTING`, `usesNonExemptEncryption=false`, назначение группе `parents` и её автоматический доступ к новым сборкам. Последняя подтверждённая доступная TestFlight-сборка — 1.0.9 (1); санитизированное подтверждение — `Artifacts/TestFlightSetup/testflight-status-109.json`.

Ошибки сертификата, профиля, прав API или обработки Apple требуют проверки конкретного запуска. Очереди и наличие hosted Mac зависят от GitHub; зелёный тестовый этап не заменяет проверку загрузки и обработки Apple. Этот процесс не развёртывает схему CloudKit Production и сам по себе не подтверждает работу общего дневника на двух физических устройствах.


## Переиспользуемая инструкция

[Инструкция и шаблоны TestFlight](https://gist.github.com/dimensi/60b088b2c3035c0351b68b7b42b866c2#file-00-readme-md) и [готовый промпт](https://gist.github.com/dimensi/60b088b2c3035c0351b68b7b42b866c2#file-01-prompt-md) предназначены для настройки выпуска в других проектах и не содержат секретов. Это отдельный playbook; действующие настройки «Малыша», сроки подписи и проверенные выпуски описаны в этом репозитории.

Минимальная система приложения, расширения и тестовых целей — iOS 26.0. Перед загрузкой Fastlane проверяет MinimumOSVersion=26.0 в архиве вместе с версией, номером сборки и декларацией шифрования приложения; для встроенного `MalyshWidgets.appex` проверяет наличие, bundle ID, ту же версию, номер сборки и MinimumOSVersion=26.0.
