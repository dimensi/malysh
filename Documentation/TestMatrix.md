# Матрица тестов

Для небольшого дневника нужен компактный набор, защищающий основные действия и данные. Не тестируем каждую функцию, ветку реализации, подпись или вариант оформления. После чистки оставлено **32 unit/integration + 8 UI**. При обновлении из `main` 6 ноября добавились 30 ранее написанных тестов новой функции фотографий: после следующего merge интерактивных виджетов фактический набор — **64 unit/integration + 21 UI**. Виджеты добавили 12 проверок команд/проекции и 3 системных сценария; старые удалённые проверки не возвращались. Тесты фотографий сохранены из upstream и этой чисткой ещё не пересматривались; увеличение не задаёт новую цель покрытия.

Перед новым тестом найдите строку матрицы и назовите конкретный пользовательский сбой. По умолчанию исправьте или замените существующий сценарий. Увеличение набора требует нового существенного риска либо воспроизводимой регрессии, которую он пока не ловит. Не переносите удалённые проверки в мегатесты или огромные таблицы ради красивого счётчика. Косметические правки проверяются вручную.

Локально они нужны при изменении схемы, schema tooling или workflow; CI также запускает их перед ручными операциями со схемой. К 85 тестам приложения они не относятся и CloudKit по сети не вызывают.

## Что проверяем вручную

Удаление теста означает сокращение автоматического покрытия. Ниже — проверки по затронутой области, а не обязательный длинный ритуал для каждой правки. Если нужного устройства/аккаунта нет, пишите «не проверено».

| Когда | Проверка |
| --- | --- |
| Меняется UI/текст/форма | Затронутый экран: светлая/тёмная тема, крупный Dynamic Type, доступность действий после прокрутки, привязка диалогов. При изменении профиля — имя/дата и повторное открытие; при изменении ошибок — сообщение и сохранение черновика. VoiceOver для затронутых подписей/контролов |
| Меняется виджет или доставка ссылки | Затронутые семейства Home/Lock Screen: данные/пусто/недоступно, темы/tinted/clear, крупный текст и privacy на устройстве. Переходы из завершённого приложения, ссылка на недоступный дневник и отсутствие записи до выбора. Холодная доставка не покрывается отдельным UI-набором |
| Меняется Live Activity или поддерживаемая iOS | Физический защищённый Lock Screen и Dynamic Island; грудь/сон, фон и завершённый процесс, переключение/завершение и сохранённая запись. Автотесты проверяют системные кнопки через Simulator Notification Center |
| Меняются общие данные/авторство/конфликты/доступ | Два Apple ID: приглашение/принятие, доставка записей/профилей, offline-правки, автор/редактор, отзыв доступа. При изменении кеша личности отдельно проверить перезапуск и выход из дневника. См. [CloudKit.md](CloudKit.md) |
| Меняются подпись/entitlements или готовится выпуск | Подпись приложения и расширения, App Group, iCloud/APNs, установка/запуск по [TestFlight.md](TestFlight.md) |

Отдельной автоматической матрицы возрастов/часовых поясов профиля, копирайтинга ошибок, всех ревизий кэша, вариантов состояния драйвера и каждой гонки нет. Существенный обнаруженный дефект может стать основанием заменить/добавить узкую регрессионную проверку.

## Запуск

`Scripts/check.sh` проверяет форматирование/lint, генерирует проект и передаёт дополнительные аргументы в `xcodebuild`. В обычной задаче выбирайте затронутую строку:

```sh
rtk proxy env RESULT_BUNDLE_PATH=Artifacts/DomainChecks.xcresult bash Scripts/check.sh \
  -only-testing:MalyshTests/DomainTests

rtk proxy env RESULT_BUNDLE_PATH=Artifacts/ActivityChecks.xcresult bash Scripts/check.sh \
  -only-testing:MalyshTests/CareActivityCoordinatorTests \
  -only-testing:MalyshTests/CareActivityActionTests \
  -only-testing:MalyshUITests/LiveActivityUITests
```

Полный набор нужен перед merge/релизом и после общей перестройки тестов:

```sh
rtk proxy env RESULT_BUNDLE_PATH=Artifacts/FullCheck.xcresult bash Scripts/check.sh
```

Отдельно для изменений схемы или её инструмента:

```sh
rtk proxy python3 -m unittest discover -s Scripts/tests -v
```

Для повторного запуска задайте новый `RESULT_BUNDLE_PATH`; устройство можно выбрать через `DESTINATION`. После успешного полного прогона повторять его без изменений не нужно. При сбое сначала разберите и повторите только упавший сценарий. Повторный успех не скрывает первую ошибку. CI TestFlight сохраняет полный прогон приложения; schema workflow запускает свои Python-проверки.

## Сокращение 5 ноября 2026

Набор приложения сокращён со 121 до 40 методов (96 → 32 unit/integration, 23 → 8 UI, 2 → 0 render). Удалены отдельный `MalyshWidgetTests` с 186 PNG, сравнение пикселей, тестовые overrides виджета и неиспользуемая фикстура авторства. Убраны многочисленные узкие вариации, повторные UI-проходы и самостоятельный набор cold URL. Сохранены основные действия, риски потери/смешения данных и минимальные системные проверки.

[Validation.md](Validation.md) и [WidgetValidation.md](WidgetValidation.md) — исторические отчёты. Их старые числа и перечисление сценариев не задают текущий состав тестов.

Проверка сокращённого набора: 32 unit/integration и 7 UI прошли в `Artifacts/TestMatrix/Compact.xcresult`. В восьмом UI-сценарии обнаружен ошибочный поиск пункта «Мокрый»: до появления диалога он выбирал одноимённый текст старой записи. Поиск исправлен; отдельный повтор прошёл в `Artifacts/TestMatrix/WidgetRetry.xcresult`. Итого проверены все 40 сценариев, но первый полный прогон содержал этот сбой. SwiftFormat, SwiftLint strict и генерация проекта прошли; 14 проверок schema tooling также прошли. Ручные проверки на физических устройствах в эту чистку не входили.

Обновление из `main` 6 ноября (`cbf8ff7`): конфликт генерируемого Xcode-проекта разрешён повторной генерацией, исправлен один отступ в `PhotoWorkflow.swift`. Форматирование/lint и сборка прошли. `Artifacts/TestMatrix/MainIntegration.xcresult`: 51 unit/integration прошёл, 1 opt-in PhotoKit пропущен по условию; UI-набор в этой проверке не запускался.

В том же обновлении подтянут следующий `main`, `e036361` (контекстное меню фотографий). После него повторно прошли сборка и lint; изменения затрагивают `PhotoGalleryView` и документацию. Модульный результат выше относится к `cbf8ff7`, UI повторно не запускался.
