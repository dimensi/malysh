# Студия материалов «Малыша»

Генератор создаёт промо для App Store, прозрачные изображения устройств для сайта и рекламные обложки. Галерея показывает каждый готовый файл с размером и отдельной кнопкой скачивания.

Текущий каталог содержит 48 изображений: 9 сюжетов iPhone в двух размерах, 3 Watch, 3 для внешнего и 3 для внутреннего экрана Duo, 16 для сайта, 2 рекламных формата App Store и 3 социальных обложки. Все шесть кадров Duo сняты на настоящих дисплеях симулятора; внутренний экран — 2853 × 2007.

## Первый запуск

Нужны Node.js 22+ и npm. Из корня репозитория выполните команды по порядку.

```sh
npm --prefix Publication/AppStore ci
npm --prefix Publication/AppStore exec -- playwright install chromium
npm --prefix Publication/AppStore run prepare-assets
npm --prefix Publication/AppStore run render
npm --prefix Publication/AppStore run gallery
```

Первая подготовка скачивает зафиксированные мокапы Plinth и проверяет SHA-256. Шаблоны и подготовленные корпуса лежат в локальной `.cache`, которая исключена из Git. Источники и условия использования перечислены в `assets/mockup-sources.json`. Результаты рендера используются для материалов приложения согласно условиям поставщика. Manrope с кириллицей поставляется локально вместе с OFL.

После подготовки рендер работает с локальными исходниками. `gallery` запускает сервер только на `127.0.0.1`, открывает браузер на macOS и завершается по Ctrl+C. Готовые файлы находятся в `output/`.

## Повторная сборка

```sh
# Все материалы
npm --prefix Publication/AppStore run render

# Один слайд в одном размере
npm --prefix Publication/AppStore run render -- --device iphone-medium --slide 05-timers

# Все изображения Apple Watch
npm --prefix Publication/AppStore run render -- --device watch

# Изображения сайта и перенос готовых файлов в Website
npm --prefix Publication/AppStore run render -- --device site
npm --prefix Publication/AppStore run site-assets

# Проверка размеров, альфа-канала и контрольных сумм
npm --prefix Publication/AppStore run validate
```

Доступные значения `--device` — `iphone-medium`, `iphone-large`, `watch`, `duo-outer`, `duo-inner`, `site`, `creative`, `social`. `--slide` принимает идентификатор из каталога, например `02-care` или `01-diary` для часов. Без фильтров создаётся весь каталог. При выборочной пересборке сохраняются остальные изображения.

## Как изменить или добавить кадр

`studio/catalog.json` хранит версию приложения, исходные снимки, тексты, порядок и композиции. `studio/template.mjs` собирает устройства и содержимое слайда, `studio/styles.css` задаёт типографику и расположение. Галерея оформлена отдельно в `studio/gallery.css` и `studio/gallery.js`.

1. Добавьте настоящий снимок в `raw/` и его происхождение в `capture/provenance.json`.
2. Добавьте путь под новым ключом `sources` в каталоге.
3. В `slides` добавьте запись с уникальным `id`, заголовком, подписью, `layout`, `tone` и ключами `screens`. Типы композиций — `single`, `family`, `pair`, `activities`, `watch`, `report`.
4. Пересоберите выбранный кадр, проверьте его в галерее в оригинальном размере и в миниатюре.

Новый размер или семейство экспорта добавляется в `studio/jobs.mjs`. Геометрию готового устройства задаёт подготовленный `assets/mockups.json`; она содержит размеры корпуса, прямоугольник экрана и скругления. Каждый экран сохраняет пропорции снимка. Изменение содержимого UI выполняется в приложении перед съёмкой.

## Результаты и сохранность

Рендер проверяет источники, загрузку шрифта, изображения и пересечения текста, затем пишет новую сборку во временную папку. `output` заменяется после успешной сборки. При ошибке предыдущие результаты остаются доступными. Одновременный второй рендер останавливается с сообщением о занятой сборке.

Набор внутреннего дисплея Duo допускает незавершённое состояние при отсутствии настоящего снимка или чёрном кадре. Галерея показывает конкретный отсутствующий файл. Ранее созданный результат такого кадра сохраняется на диске, а карточка явно требует новой съёмки.

`output/contact-sheet.png` — общий лист превью; `output/iphone-contact.png` — последовательность iPhone. Они обновляются при каждом успешном рендере.

`output/manifest.json` содержит размеры, SHA-256, модель мокапа, версию, commit и происхождение каждого изображения. Галерея и изображения служат для ручного выбора и загрузки. `site-assets` копирует только перечисленные в манифесте материалы и шрифт в `Website`; сайт публикуется штатным процессом Cloudflare Pages.

## Настоящие экраны приложения

Исходная база материалов — версия 1.13.0 с PDF-отчётом. Пофайловое происхождение указано в `capture/provenance.json`. Съёмка использует отдельный симулятор и синтетические данные Ванечки, Лены и Миши. Инструкция и команды находятся в `capture/README.md`.

Для рендера сохранённых кадров Xcode не нужен. Обновляйте снимки и базовую версию в каталоге вместе, чтобы в промо попадали реализованные функции актуальной сборки.

## Композиция Live Activities

Кадр «Важное всегда на виду» — редакционная витрина вариантов, а не снимок одновременного состояния iOS. Раскрытый Dynamic Island кормления и карточки сна/напоминания взяты из трёх настоящих системных снимков. На одном фоне показаны неизменённые нативные карточки; подпись «Варианты Live Activities» обозначает композицию.

`studio/catalog.json → compositions.liveActivities` хранит исходный размер, полные прямоугольники карточек, скругления и положение в корпусе. Генератор проверяет, что координаты соответствуют исходнику, сохраняет пропорции и записывает crop-геометрию вместе с SHA исходных кадров в манифест результата. При новой съёмке геометрию нужно проверить заново. Тексты, цвета и элементы настоящих карточек не перерисовываются.
