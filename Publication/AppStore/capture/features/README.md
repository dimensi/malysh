# Дополнительные настоящие системные состояния

`FeatureScenes.swift` подключается основным `../capture-iphone.sh` в временную сборку выбранного release ref. Отдельной подмены PDF-исходников больше нет: экспорт доступен в релизе 1.13.0.

Сценарий `StorefrontFeatureScenes/testReminder` включает штатный переключатель напоминания, ожидает настоящее системное уведомление/Live Activity, сохраняет снимок и отключает переключатель после съёмки. `StorefrontFeatureScenes/testPediatricianPDF` открывает реальный экран экспорта.
