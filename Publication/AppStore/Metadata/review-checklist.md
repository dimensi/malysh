# До отправки на App Review

Рабочая база новых материалов — `6001cb1` (`v1.13.0`). При последней проверке ASC первый публичный черновик имел номер `1.0` и выбранную сборку `1.12.0 (1)`. Перед отправкой нужно повторно сверить выбранный build, наличие PDF и рабочих ссылок на поддержку и политику. Номер страницы должен совпадать с окончательным подписанным архивом. [Выбор сборки](https://developer.apple.com/help/app-store-connect/manage-builds/choose-a-build-to-submit) · [Правила App Review, 2.1 и 5.1.1](https://developer.apple.com/app-store/review/guidelines/)

## 1. Страницы, декларации и доступность

- [ ] [Поддержка](https://malysh.dimensi.dev/support) и [политика](https://malysh.dimensi.dev/privacy) опубликованы и отвечают HTTP 200. Владелец должен подтвердить и добавить прямой контакт поддержки. Сейчас указан публичный GitHub Issues, который требует аккаунта и не подходит для приватных обращений. Сверить контакт с требованиями Apple и целевых регионов, проверить обе страницы с iPhone. [Требования к Support URL](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information)
- [ ] Сделать ссылку на политику видимой и доступной в приложении. Проверить переход в подписанной сборке. Для первого запуска желательно оставить возможность открыть политику с экрана приветствия и из «Настроек».
- [ ] Подтвердить правообладателя и год для Copyright, права на референс иконки и использованные иллюстрации. Ответить на Content Rights. Убедиться, что в кадрах используются только разрешённые синтетические материалы.
- [ ] Сверить политику и App Privacy с фактическим доступом владельца и его партнёров к данным, диагностикой App Store Connect и публичной формой или адресом поддержки. Сохранить подтверждённые ответы. [App Privacy Details](https://developer.apple.com/app-store/app-privacy-details/)
- [ ] До отправки получить разъяснение Apple о применимости §5.1.3(ii) к введённым вручную измерениям ребёнка. Вес, рост и окружность головы сохраняются в закрытых зонах CloudKit, если включена синхронизация. Правило запрещает хранение персональной информации о здоровье в iCloud. Это отдельный вопрос от этикетки App Privacy. Если Apple отнесёт эти данные к правилу, изменить хранение и привести описание и политику в соответствие до нового архива. [Матрица проекта](../AppPrivacy.md) · [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/#health-and-health-research)
- [ ] Убедиться, что аккаунт разработчика активен и актуальные соглашения приняты. Подтвердить территории и ценовой режим, в том числе доступность России. Язык страницы и территориальная доступность настраиваются независимо. Если выбраны страны ЕС, заполнить декларацию статуса продавца по DSA. [Территории](https://developer.apple.com/help/app-store-connect/manage-your-apps-availability/manage-availability-for-your-app-on-the-app-store) · [Действующие требования Apple](https://developer.apple.com/news/upcoming-requirements/)

## 2. Возрастная анкета

App Information → Age Rating → Edit. Приложение адресовано взрослым, которые ведут записи об уходе за ребёнком. Если фактическая анкета соответствует проверенному коду, по проверенным функциям нет очевидного основания поднимать базовую оценку 4+. Анкета заполнена. App Store Connect сохранил 4+ как базовый рейтинг и рассчитывает местные значения автоматически. [Настройка рейтинга](https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-app-age-rating) · [Определения полей](https://developer.apple.com/help/app-store-connect/reference/app-information/age-ratings-values-and-definitions)

| Вопрос | Ответ по проверенному коду |
| --- | --- |
| Parental Controls, Age Assurance | No. Дневник для родителей, встроенной проверки возраста и ограничений доступа по возрасту нет. |
| Unrestricted Web Access | No. Встроенного браузера общего назначения нет. |
| User-Generated Content, Social Media | No по определению Apple о широком распространении. Фото и заметки доступны только владельцу и приглашённому участнику выбранного дневника. В приложении нет публичной ленты и поиска пользователей. |
| Messaging and Chat | No. Есть системное приглашение в дневник, встроенного общения нет. |
| Advertising | No. Рекламные SDK и рекламные места отсутствуют. |
| Medical or Treatment Information | None. Пользователь записывает фактические события и измерения. Приложение не оценивает симптомы и не предлагает лечение. |
| Health or Wellness Topics | Сверить определение в действующей форме. По текущему определению Apple о рекомендациях — No: графики отражают записи, а интервал напоминаний выбирает родитель. Если актуальная формулировка включает ведение журнала ухода без советов, отметьте наличие. |
| Прочие темы, насилие, ненормативная лексика, азартные игры, конкурсы | None / No по каждому пункту. Используйте актуальную форму. |
| Age Categories and Override | Not Applicable. Укажите более высокий рейтинг, если этого требуют условия использования или местные правила. |

## 3. Подписанная версия

- [ ] Согласовать номер первого публичного релиза. Обновить номер версии в редактируемом первом черновике `1.0` в соответствии с окончательным архивом. Точный номер выбирает владелец. Если интерфейс не разрешит изменить номер, используйте поддерживаемый Apple путь через управление версией или Developer Support и сохраните существующую запись приложения `6830627364`.
- [ ] Подтвердить успешный штатный CI с тестами и четырьмя профилями подписи (`dev.dimensi.malysh`, `.widgets`, `.watchkitapp`, `.watchkitapp.widgets`), Production CloudKit, корректным bundle ID сопряжения и одинаковыми номером версии и номером сборки во всех продуктах. Текущий Fastlane при повторе тега использует уже загруженный build. Для нового бинарника нужен новый одобренный номер версии по штатной процедуре, либо согласованное изменение процесса для следующего build того же номера. [Инструкция проекта](../../../Documentation/TestFlight.md) · [Требования Apple к SDK](https://developer.apple.com/news/upcoming-requirements/)
- [ ] В ASC выбрать обработанный build без блокирующих предупреждений. Проверить семейства устройств в метаданных архива. Минимум приложения iOS 27.0, часов watchOS 26.0. Apple Watch — companion для сопряжённого iPhone. iPad не объявлять как поддерживаемую нативную платформу. Сверить отображение приложения для Mac с Apple silicon и Apple Vision Pro, если ASC предлагает отдельное включение совместимости. Включать только проверенную владельцем доступность.
- [ ] Сверить ответ об экспортном соответствии с финальной сборкой. В текущем архивировании Fastlane проверяет `ITSAppUsesNonExemptEncryption = false`. Если появились сторонняя криптография или иной профиль использования, оценить вопрос заново. [Export compliance Apple](https://developer.apple.com/help/app-store-connect/manage-app-information/overview-of-export-compliance/)
- [ ] Проверить свежую установку и локальное создание дневника без входа в аккаунт приложения. Запись, редактирование, удаление, статистика, измерения, PDF, JSON и импорт фото должны работать с реалистичным тестовым сценарием. Проверить разрешения, светлую и тёмную темы, крупный текст, переходы Live Activity и виджетов. Убедиться, что материалы показывают именно финальную реализацию.
- [ ] На двух подписанных iPhone с разными тестовыми Apple Account проверить включение iCloud, приглашение, принятие, двустороннее обновление событий и фото, отзыв доступа, повторную попытку и локальный режим. Сверить Production CloudKit со схемой репозитория и проверить Production после любого разрешённого переноса. [Облачная схема проекта](../../../Documentation/CloudKitSchema.md)
- [ ] На подписанной физической паре iPhone и Watch проверить первоначальное получение дневника, запись без связи, доставку очереди после восстановления, отсутствие дублей, переходы с циферблата и Smart Stack. Экранный прогон на симуляторе подтверждает только показ и локальные сценарии. [Приёмка Watch](../../../Documentation/AppleWatch.md)
- [ ] Для карточки Duo проверить переключение внешнего и внутреннего экранов, отсутствие обрезок и доступность кнопок в вертикальной системной панели. Загружать отдельные кадры Duo после этой проверки. [Чеклист Apple для Duo](https://developer.apple.com/iphone-duo/prepare/)

## 4. Черновик карточки

- [ ] В локализации Russian внести [проверенные тексты](README.md), действующие HTTPS URL и подтверждённый Copyright. Сохранить оба уровня метаданных, App Information и iOS Version. Дать имена и URL на подтверждение владельцу.
- [ ] Загрузить комплект iPhone Dynamic Island и комплект Apple Watch по [порядку загрузки и размерам](../UPLOAD_ORDER.md). По возможности добавить оба подтверждённых состояния Duo. Проверить порядок кадров, подписи и соответствие экранов языку карточки. Для Header и Search Results использовать Preview после загрузки.
- [ ] Для App Review Information добавить [пояснение ревьюеру](review-notes.en.txt) и действующие приватные контакты. Sign-in required выключить для основного локального режима. Для проверки семейного сценария использовать системные iCloud-аккаунты ревьюера или согласованный с Apple тестовый способ. Не прикладывать личные пароли и данные семьи.
- [ ] Декларация о регулируемом медицинском устройстве, если поле появляется для выбранных рынков, заполняется владельцем исходя из фактической функциональности. Дневник хранит записи, не предоставляет медицинских выводов. Accessibility Nutrition Labels заполнить только по результатам проверки распространённых сценариев на iPhone и Watch. [Требования к проверке доступности](https://developer.apple.com/help/app-store-connect/manage-app-accessibility/overview-of-accessibility-nutrition-labels)
- [ ] Включить **Manually release this version**. Сохранить черновик и пройти визуальную проверку. После отдельного разрешения владельца отправить версию и материалы на ревью. После одобрения отдельно согласовать ручной публичный выпуск. [Отправка версии на App Review](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/submit-an-app/) · [Ручной выпуск версии](https://developer.apple.com/help/app-store-connect/manage-your-apps-availability/select-an-app-store-version-release-option)
