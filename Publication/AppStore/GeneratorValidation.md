# Проверка генератора материалов

База приложения: 1.13.0, commit `6001cb1`; точные исходные commit, устройства, runtime, размеры и SHA каждого кадра находятся в `capture/provenance.json` и `output/manifest.json`.

## Итоговая сборка

Успешно созданы **48 из 48** изображений, незавершённых позиций нет:

| Набор | Количество | Размер |
| --- | ---: | --- |
| iPhone | 9 + 9 | 1206 × 2622; 1320 × 2868 |
| Apple Watch | 3 | 422 × 514 |
| Duo внешний | 3 | 1398 × 2034 |
| Duo внутренний | 3 | 2853 × 2007 |
| Сайт | 16 | Индивидуальные прозрачные WebP; обложка 1200 × 630 |
| Header / Search Results | 2 | 3840 × 1646; 1920 × 1280 |
| Соцсети | 3 | 1600 × 900; 1080 × 1350; 1080 × 1920 |

`npm run validate` подтвердил размеры, sRGB, отсутствие альфа-канала у PNG для App Store и совпадение SHA всех 48 результатов. У всех использованных исходников есть пофайловое происхождение; `unknown` отсутствует. Во время рендера проверены загрузка локального Manrope, декодирование изображений, пропорции источников, отсутствие выхода устройств за холст и пересечения заголовков с корпусами.

## Сохранность и повторяемость

- Выборочный повтор `iphone-medium/02-care` после полной сборки не изменил ни один из 48 PNG/WebP; итоговый `manifest.json` совпал побайтно.
- Результат `05-timers` совпал по SHA между выборочным и полным рендером.
- В изолированной копии отсутствие настоящего источника остановило сборку с конкретным именем файла; прежний результат сохранён.
- Подстановка кадра Watch 422 × 514 в iPhone отклонена с объяснением несовпадения геометрии и названием модели.
- Чёрные кадры внутреннего Duo, в том числе неверного внешнего размера 1398 × 2034, получили статус `incomplete` с точным именем источника. Они не были выданы за готовое промо.
- Реальная замена исходного Watch-файла во время промежуточного рендера обнаружена по SHA; прежний `output` сохранён, после завершения съёмки выполнен успешный повтор.
- Полный и выборочный рендеры автоматически обновляют галерею и оба контактных листа. Удалённый отдельный слайд напоминания исключён из каталога, манифеста и готовой папки.

## Галерея

Проверены ширины **390, 768, 1024 и 1440 px**, горизонтального переполнения нет. Фильтры показывают: iPhone 18, Watch 3, Duo 6, сайт 16, App Store 2, соцсети 3. Проверены открытие клавишей Enter, закрытие Escape с возвратом фокуса, отдельная вкладка оригинала и настоящее скачивание PNG. Скачанный Watch-файл имеет 422 × 514 и совпадает по SHA с манифестом. JavaScript-ошибок нет. Режим уменьшенного движения проверен в браузере.

## Визуальная проверка

Исправлены большие промежутки над устройствами, семейные телефоны равного масштаба, Watch использует настоящий корпус с ремешком. Header и Search Results имеют самостоятельные композиции. Inner Duo содержит цельный реальный развёрнутый экран; внешние и внутренние экраны не подменяются друг другом.

`05-timers` — явно подписанная редакционная композиция вариантов Live Activities: настоящие неизменённые карточки кормления, сна и напоминания внутри одного корпуса. Это не утверждение об одновременном системном состоянии. Crop-геометрия и исходные SHA записаны в манифесте. Остальные устройства содержат целые снимки с сохранением пропорций.

Технические проверки генератора не заменяют финальную ручную загрузку и проверку доступности рекламных слотов в App Store Connect. Генератор не публикует сайт и не отправляет приложение на ревью.

## Сайт

Лендинг, поддержка и политика проверены на 390, 768, 1024 и 1440 px. После объединения системных карточек повторно проверены четыре ширины: нет горизонтального переполнения, Manrope загружен, все изображения декодируются, внутренние якоря существуют, первым фокусируется ссылка «К содержанию». Проверен режим уменьшенного движения. Отдельный ручной просмотр подтвердил правильные размеры корпусов и внешнюю подпись композиции Live Activities.

Cloudflare Pages обновляется штатным Direct Upload. Локальная авторизация Wrangler проверена и имеет pages:write. Workflow Website уже подготовлен для main; секрет CLOUDFLARE_API_TOKEN в GitHub пока не настроен. OAuth-профиль cf не имеет доступа к выпуску account API tokens (Cloudflare вернул 403), поэтому для включения CI нужен отдельный ключ Pages Edit. Повторный вход для разового обновления сайта не требуется.
